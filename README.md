# حسابدار شخصی من — اپلیکیشن اندروید

این پروژه نسخه اندرویدی برنامه حسابداری شماست و رابط HTML را در WebView اجرا می‌کند.

## ساخت APK بدون نصب Android Studio (با GitHub Actions)
1. فایل ZIP پروژه را از حالت فشرده خارج کنید.
2. در GitHub یک مخزن جدید بسازید و تمام محتویات پوشه `hesabdar-android` را در آن بارگذاری کنید (ساختار پوشه‌ها حفظ شود).
3. وارد تب **Actions** مخزن شوید و در صورت درخواست، گزینه فعال‌سازی workflowها را بزنید.
4. اجرای **Build Android APK** را انتخاب و روی **Run workflow** بزنید. اگر فایل‌ها را روی شاخه `main` بارگذاری کنید، ساخت خودکار هم آغاز می‌شود.
5. پس از پایان موفق، وارد همان اجرای workflow شوید، بخش **Artifacts** را باز کنید و `hesabdar-personal-apk` را دانلود کنید.
6. ZIP دانلودشده را باز کنید و فایل `app-debug.apk` را روی گوشی اندرویدی نصب کنید. ممکن است Android اجازه نصب از منبع ناشناس را بخواهد؛ فقط در صورتی اجازه دهید که فایل را از اجرای موفق مخزن خودتان گرفته باشید.

## ساخت با Android Studio
1. پوشه پروژه را در Android Studio با گزینه **Open** باز کنید.
2. صبر کنید Gradle Sync و نصب Android SDK انجام شود.
3. از مسیر **Build > Build Bundle(s) / APK(s) > Build APK(s)** خروجی بگیرید.

حداقل نسخه اندروید: Android 6.0 (API 23).

## نکات مهم
- داده‌های مالی در حافظه داخلی WebView همین نصب ذخیره می‌شوند؛ پاک‌کردن داده برنامه یا حذف نصب می‌تواند آن‌ها را پاک کند. مرتب نسخه پشتیبان بگیرید.
- قیمت‌های بازار برای دریافت به اینترنت نیاز دارند.
- فایل APK امضای انتشار (release) ندارد؛ این خروجی debug برای نصب شخصی است.
